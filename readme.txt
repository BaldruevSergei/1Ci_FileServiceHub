FileServiceHub

Описание проекта
Проект FileServiceHub представляет собой 4 модуля:

1. file-processing-service
   - Отвечает за обработку файлов, включая загрузку, парсинг, сохранение и манипуляцию данными.

2. logging-service (в процессе реализации)
   - Назначение: централизованное управление логированием событий.

3. rule-management-service (в процессе реализации)
   - Назначение: управление правилами обработки данных.

4. browser-plugin-service
   - Отдельный проект для плагина Google Chrome.

Преимущества модульной структуры
- Модульность: Каждый модуль изолирован, что облегчает внесение изменений и исправление ошибок.
- Масштабируемость: Можно разрабатывать и развертывать модули независимо друг от друга.
- Поддерживаемость: Проще добавлять новые функции или заменять существующие модули.
- Тестирование: Каждый модуль можно протестировать отдельно, обеспечивая стабильность системы.

file-processing-service

Основной функционал
1. Загрузка и парсинг файла через API с выделением строк NStr, сохраняемых во временный файл.
2. Хранение временных данных в отдельной директории, задаваемой через настройки.
3. Обработка данных с формированием выходного файла в формате "номер строки: язык: текст".
4. Очистка временного файла вручную через эндпоинт или автоматически при старте приложения.
5. Выходной файл сохраняется в текстовом формате.
6. Логирование ошибок для упрощения поиска проблем.
7. Использование микросервисной архитектуры для масштабируемости.
8. Возможность добавления базы данных в будущем (временные файлы используются в текущей версии).
9. DTO (ParsedResult) для передачи данных между частями приложения.

Покрытие тестами
- Покрытие тестами составляет 75%, что обеспечивает стабильность работы модуля.

Возможности управления временными файлами
- Механизм ротации или ограничения размера файла.
- Опция для очистки данных вручную или автоматически.
- Логирование изменений файла.

Инструкция по запуску
1. Клонирование репозитория:
   ```bash
   git clone https://github.com/BaldruevSergei/1Ci_FileServiceHub.git
   cd 1Ci_FileServiceHub
   ```
2. Установка зависимостей:
   - Убедитесь, что установлены Java 17+ и Gradle (или используйте Gradle Wrapper).
3. Запуск проекта:
   ```bash
   ./gradlew bootRun
   ```
   Для Windows:
   ```bash
   gradlew.bat bootRun
   ```
4. Доступ к приложению:
   - Приложение доступно по адресу: http://localhost:8081
   - Swagger UI: http://localhost:8081/swagger-ui/index.html

browser-plugin-service

Цель
Создать плагин для Google Chrome, который заменяет все буквы "а" на случайные числа (0-9) на активной странице.

Основные функции
- Start Replacement: Находит буквы "а" и заменяет их случайными цифрами.
- Stop Replacement: Останавливает замену и возвращает оригинальный текст.
- Resume Replacement: Снова запускает замену текста.

Реализация проекта
- UI на React:
  - Три кнопки: "Start Replacement", "Stop Replacement", "Resume Replacement".
- Content Script:
  - Логика замены текста и отслеживание изменений через MutationObserver.
- Manifest v3:
  - Настройка подключений и отображения всплывающего окна.

Стек технологий

- Язык программирования: Java 17+
- Фреймворк: Spring Boot

- API-документация: Swagger/OpenAPI

Frontend (JavaScript)

- Фреймворк: React

Дополнительно

- Хранение временных данных: Файлы
- Логирование: Централизованный logging-service
